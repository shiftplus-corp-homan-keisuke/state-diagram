# P2 Advanced State Intelligence

## Goal
高度な状態管理パターン、オンボーディング、差分理解、生成支援を追加し、状態理解ツールとしての完成度を引き上げる。

## Tasks
- [ ] 状態モデルを拡張する → Verify: server/cache/loading/error/retry/optimistic/derived などを表現できる
- [ ] 高度状態向けの可視化ルールを追加する → Verify: 新しい状態種別が誤読されにくく表示される
- [ ] オンボーディング UI を追加する → Verify: 読む順番、重要ノード、注意点を案内できる
- [ ] JSON 差分比較機能を追加する → Verify: before/after の変更箇所を状態フローとして比較できる
- [ ] 代表ユースケースのテンプレート/プリセットを整備する → Verify: LLM に再利用しやすい入力資産が増える
- [ ] 半自動生成の入口を検討・実装する → Verify: store 名や hook 名などから補助情報を作れる
- [ ] P2 用の回帰テストを追加する → Verify: 新モデルと比較機能の退行を検知できる

## Recommended Order
1. 状態モデル拡張
2. 可視化ルール
3. オンボーディング
4. 差分比較
5. テンプレート
6. 半自動生成
7. テスト

## Notes
- P2 は P1 の UX/仕様が安定してから着手する
- 表現力追加で複雑化しすぎないよう、凡例とガイドを同時に整備する

## Done When
- [ ] 現代的フロントエンド状態管理をより自然に表現できる
- [ ] 初見ユーザーの理解導線がアプリ内で完結する
- [ ] 比較・テンプレート・補助生成で運用コストが下がる
